# DesxusHub — できた版の置き場

DesxusHub の**できあがったものだけ**を置いています。ソースはここにはありません。

## 入れ方

1. 下の [Releases](../../releases/latest) から `DesxusHub_vX.Y.Z.zip` を落とす
2. 好きなところに展開する（おすすめ: `ドキュメント\DesxusHub\app`）
3. `DesxusHub.exe` を起動する

初回に、Windows と一緒に起動するタスクを登録します。切りたいときは設定ページから。

## 新しい版

アプリが 6 時間ごとに自分で見に来ます。見つけても**勝手には入れ替えません**。
設定ページの「更新」から「入れ替える」を押したときだけ入れ替わります。

## 動かすのに要るもの

- Windows 10/11（64 ビット）
- 追加の .NET は要りません（中に入っています）

## 最初に入れておくとよいもの

| したいこと | 要るもの | 入れるところ |
|---|---|---|
| 相棒ミニ・ノートの AI・残高 | DeepSeek の API キー | 「残高」ページ |
| こよみ・書類 | Google の `client_secret.json` | `ドキュメント\DesxusHub\` に置く |
| 即席ラジオ | 効果音（wav）と MIDI のフォルダー | 「ラジオ」ページで指定 |

無くても、ほかのところ（帯・付箋・音声ミキサー・写真・録音・偽画面・机）はそのまま使えます。
